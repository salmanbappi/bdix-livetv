# BDIX Live TV Extension

Aniyomi extension for BDIX Live TV streams.

## 📡 Repository Info
- **GitHub Path:** [salmanbappi/bdix-livetv](https://github.com/salmanbappi/bdix-livetv)
- **Base URL:** `http://172.16.29.28`
- **Build Status:** Automated via GitHub Actions

## 🛠️ Features
- **Website Scraping:** Direct extraction from `172.16.29.28`.
- **M3U Support:** Load custom playlists from `http://172.16.29.34/playlist.m3u`.
- **Xtream API:** Integration with the `ontest1` server.

## 🚀 Automation
This repository uses `GH_PAT` to automatically sync built APKs to the [extensions-repo](https://github.com/salmanbappi/extensions-repo).
